# Bundled fonts

`SourceSans3-*.ttf` — Source Sans 3, version 3.052R, © Adobe. Licensed under
the SIL Open Font License 1.1 (https://openfontlicense.org), which permits
bundling and redistribution with software. Source and full licence text:
https://github.com/adobe-fonts/source-sans

`plotting_utils.register_fonts()` adds these to matplotlib's font manager at
runtime; nothing needs to be installed system-wide.
